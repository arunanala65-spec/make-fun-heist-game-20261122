The Velvet Vault is a top-down heist game — cross the room, dodge guard vision cones and sweeping cameras, grab the loot, watch the alarm meter, reach the getaway. Three rooms (the Gallery, the Vault, the Penthouse), patrols you have to read before you move, and tools at a cost: coin tosses to distract, smoke to blind, an EMP to freeze the cameras.

## Run it

```sh
python3 -m http.server --directory game 8080
```
Then open http://localhost:8080 in a desktop browser. (Or open game/index.html directly; no build step, no network.)
